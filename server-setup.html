РАЗДЕЛ 01

Что понадобится для своего сервера

Сервер Minecraft Java Edition — отдельная программа, которая запускает мир и обрабатывает действия игроков. Твой компьютер или арендованный хостинг должен оставаться включённым, пока друзья играют на домашнем сервере.

Перед началом подготовь:

  • Компьютер или хостинг. Чем больше игроков, модов и построек, тем выше требования к процессору, памяти и стабильности системы.
  • Подходящую Java. Её версия должна соответствовать выбранной версии Minecraft и серверного ПО.
  • Папку сервера. Храни файлы сервера отдельно от папки клиента Minecraft.
  • Доступ администратора. Для установки Java и изменения правил брандмауэра могут понадобиться права администратора.
  • Резервные копии. Создай место для копии мира до установки модов, плагинов и обновлений.
Локальный сервер или хостинг?

Домашний сервер подходит для игры небольшой компании, когда компьютер можно оставлять включённым. Хостинг удобнее, если сервер должен работать постоянно или домашнее подключение не позволяет друзьям подключаться извне.

РАЗДЕЛ 02

Выбери тип серверного ПО

Сначала реши, какой сервер ты хочешь. Клиентские моды и серверные плагины — не одно и то же, а разные загрузчики не являются взаимозаменяемыми.

VanillaОфициальный сервер без сторонних модификаций. Подходит для классического выживания и простого старта.
PaperСервер на основе Bukkit/Spigot с поддержкой плагинов и дополнительными настройками. Часто выбирают для серверов с плагинами и оптимизацией.
FabricЗагрузчик модов. Подходит для серверных модов и сборок, где важны лёгкость и гибкость. Проверяй, нужен ли каждому моду сервер, клиент или обе стороны.
Forge / NeoForgeЗагрузчики для модифицированных серверов. Используй подходящий установщик и одинаковые версии игры, загрузчика и требуемых модов.
Не смешивай несовместимые файлы

Плагины Paper не устанавливаются как обычные Forge-моды. Не загружай случайный JAR в папку mods или plugins: сначала проверь документацию выбранной платформы и совместимость файла.

РАЗДЕЛ 03

Установи подходящую Java

Серверный файл .jar запускается через Java. Важно установить не просто «самую новую Java», а версию, которую требует именно твоя версия Minecraft и выбранный серверный проект.

  1. Открой документацию или страницу загрузки выбранного серверного ПО.
  2. Найди требование к версии Java для своей версии игры.
  3. Установи 64-битную Java подходящей версии из надёжного источника.
  4. Открой командную строку и проверь установку командой java -version.
Версия Java зависит от версии игры

Например, актуальная таблица Paper указывает Java 21 для Paper 1.20–1.21.11 и Java 25 для 26.1+. Для другой версии ориентируйся на её собственные требования, а не копируй номер из этого примера.

Если команда java не найдена, Java может быть не установлена или не добавлена в PATH. Открой новое окно терминала после установки и проверь команду ещё раз.

РАЗДЕЛ 04

Скачай серверные файлы

Создай отдельную папку, например Minecraft-Server. Не запускай сервер прямо из папки «Загрузки» и не смешивай его файлы с игровыми мирами клиента.

1

Для Vanilla открой официальный сайт Minecraft и скачай серверный файл для нужной версии Java Edition.

2

Для Paper используй официальный раздел загрузки PaperMC и выбери сборку, соответствующую версии Minecraft.

3

Для Fabric, Forge или NeoForge используй официальный сайт соответствующего загрузчика и следуй его инструкции по установке сервера.

4

Перемести серверный JAR или созданные установщиком файлы в папку сервера. При необходимости переименуй JAR в простое имя, например server.jar или paper.jar.

РАЗДЕЛ 05

Первый запуск и EULA

Первый запуск создаёт конфигурационные файлы и папку мира. На этом этапе сервер может сразу завершить работу — для Vanilla это ожидаемо, если нужно сначала ознакомиться с лицензионным соглашением.

  1. Открой папку сервера.
  2. Запусти JAR через терминал или временный файл запуска. Для Vanilla команда обычно выглядит как java -jar server.jar nogui (замени имя файла на своё).
  3. После первого запуска найди файл eula.txt.
  4. Открой ссылку на Minecraft EULA внутри файла или на официальном сайте и прочитай условия.
  5. Только если ты согласен с соглашением, измени eula=false на eula=true и сохрани файл.
  6. Запусти сервер ещё раз.
Не ставь eula=true автоматически

Изменение значения означает согласие с лицензионным соглашением. Сделай это только после того, как прочитал условия и согласен с ними.

При успешном запуске в окне консоли появится сообщение о готовности сервера, обычно с текстом Done. Не закрывай это окно, пока сервер работает.

РАЗДЕЛ 06

Сделай удобный файл запуска

Чтобы каждый раз не вводить команду вручную, создай в папке сервера файл запуска. На Windows это может быть start.bat, на Linux — start.sh. Укажи точное имя своего JAR-файла.

Пример для Windows (Vanilla)

@echo off
java -Xms2G -Xmx4G -jar server.jar nogui
pause

Пример для Paper

@echo off
java -Xms2G -Xmx4G -jar paper.jar --nogui
pause

Сохрани файл с расширением .bat, а не .txt. Двойной щелчок по нему запустит сервер. Команда pause оставляет окно открытым, чтобы можно было прочитать сообщение об ошибке.

Что означают параметры памяти?

  • -Xms2G — начальный объём памяти для Java.
  • -Xmx4G — максимальный объём памяти, который Java сможет использовать.
  • nogui или --nogui — запуск без графического окна, если это поддерживает выбранный сервер.
Не выделяй всю оперативную память

Числа 2G и 4G — только пример команды, а не универсальная рекомендация. Оставь память для Windows, Minecraft-клиента и других программ. Требования зависят от количества игроков, модов, плагинов и размера мира. Если не уверен, начни с умеренного значения и следи за использованием памяти.

РАЗДЕЛ 07

Настрой server.properties

После первого запуска в папке появится server.properties. Останови сервер командой stop перед редактированием файла, затем открой его обычным текстовым редактором. После изменений сохрани файл и запусти сервер снова.

Полезные основные параметры

gamemode=survivalРежим игры по умолчанию: survival, creative, adventure или spectator.
difficulty=normalСложность: peaceful, easy, normal или hard.
max-players=10Максимальное число одновременных игроков. Выбирай значение по возможностям сервера.
motd=My Minecraft ServerСообщение, которое отображается в списке серверов у игроков.
server-port=25565Сетевой порт сервера Java Edition по умолчанию. Меняй его только при необходимости и согласованно настрой сеть.
server-ip=Обычно оставь значение пустым. Не вписывай сюда публичный IP или случайный адрес — неверное значение может помешать запуску.
online-mode=trueОставь включённым для обычного сервера с проверкой учётных записей. Не отключай ради обхода проверки: это ослабляет защиту и допускает подмену имён.
white-list=trueВключает список разрешённых игроков. Добавляй туда только тех, кому действительно нужен доступ.
view-distance=8Пример расстояния прорисовки на сервере. Снижение может уменьшить нагрузку, но меняет видимую дальность.
simulation-distance=6Пример расстояния симуляции. Влияет на область, где сервер обновляет игровой мир.

Не все параметры доступны или работают одинаково во всех серверных сборках. Если параметра нет в файле, проверь документацию своей платформы. Меняй по одному-два значения и проверяй результат.

РАЗДЕЛ 08

Whitelist, операторы, моды и плагины

Разреши вход только знакомым

В консоли сервера можно использовать команды:

whitelist on
whitelist add ИмяИгрока
whitelist list

Чтобы убрать игрока из списка, выполни whitelist remove ИмяИгрока. Имя вводится без пробелов и должно соответствовать имени игрока.

Выдавай права оператора осторожно

op ИмяИгрока
deop ИмяИгрока

Оператор (OP) получает широкие административные возможности. Не выдавай OP всем друзьям: обычно достаточно whitelist, а повышенные права нужны только доверенным администраторам.

Моды и плагины

  • Vanilla: не поддерживает Bukkit-плагины и Forge/Fabric-моды без отдельного серверного ПО.
  • Paper: использует папку plugins. Скачивай плагины с официальной страницы проекта и проверяй их версию.
  • Fabric / Forge / NeoForge: серверные моды размещаются по инструкции загрузчика, часто в папке mods. Некоторым модам требуется установка и на стороне клиента.
Совместимость важнее количества дополнений

У всех игроков должны совпадать версия Minecraft и необходимые версии загрузчика/модов. Перед установкой нового плагина или мода останови сервер и сделай резервную копию.

РАЗДЕЛ 09

Подключи друзей

Сначала проверь сервер на своём компьютере

Когда сервер запущен на том же компьютере, открой Minecraft Java Edition той же версии и подключись к адресу localhost. Если это работает, серверная программа запущена локально.

Подключение в одной домашней сети

  1. На компьютере-хосте открой командную строку и введи ipconfig.
  2. Найди IPv4-адрес активного сетевого адаптера, например 192.168.1.25.
  3. Другой игрок в той же сети вводит этот локальный адрес в поле адреса сервера.

Подключение друзей через интернет

Для прямого подключения извне обычно требуются правило брандмауэра и настройка переадресации TCP-порта сервера (по умолчанию 25565) на локальный адрес компьютера-хоста. Точные меню зависят от модели роутера и провайдера.

  1. Убедись, что сервер стабильно запускается и локально доступен.
  2. Разреши серверному приложению входящие подключения в брандмауэре. Не отключай брандмауэр целиком.
  3. С настройкой роутера попроси помочь владельца домашней сети или взрослого, который отвечает за роутер.
  4. Передавай адрес подключения только людям, которых ты знаешь и которым доверяешь.
Не публикуй домашний IP открыто

Публичный IP может раскрывать информацию о твоём интернет-подключении. Не размещай его в открытых чатах и на сайтах. Не настраивай переадресацию портов без понимания последствий. Если провайдер использует CGNAT, обычная переадресация может не работать — уточни доступные варианты у провайдера или выбери хостинг/частное решение для подключения.

РАЗДЕЛ 10

Резервные копии и обновления

Мир — самая ценная часть сервера. Ошибка при обновлении, несовместимый плагин или повреждение файлов могут привести к потере прогресса. Делай резервную копию до любых крупных изменений.

1

В консоли сервера выполни save-all, чтобы сохранить изменения мира.

2

Заверши работу командой stop. Дождись полного закрытия сервера.

3

Скопируй всю папку сервера в другое место или на отдельный носитель. Не храни единственную копию рядом с оригиналом.

4

Обновляй сервер, Java, моды и плагины по одному компоненту. После каждого изменения запускай тест и проверяй консоль.

Для обновления версии Minecraft заранее проверь совместимость плагинов, модов и загрузчика. Не открывай единственную копию мира новой версией, пока не создал резервную копию: иногда обратное открытие старого мира невозможно или небезопасно.

Перед остановкой используй команду stop

Не закрывай окно сервера крестиком и не выключай компьютер во время сохранения мира. Штатная команда stop позволяет серверу завершить работу корректно.

РАЗДЕЛ 11

Решение частых проблем

Сервер пишет, что нужно принять EULA

Открой eula.txt, прочитай соглашение и, только если согласен, замени eula=false на eula=true. Сохрани файл и запусти сервер снова.

Появляется ошибка UnsupportedClassVersionError

Чаще всего запущена неподходящая версия Java. Сверь требование к Java для конкретной версии сервера, установи её и проверь команду java -version.

Пишет Failed to bind to port

Порт может уже использоваться другой программой или адрес в server-ip указан неправильно. Для обычной домашней настройки оставь server-ip= пустым и проверь, не запущен ли второй экземпляр сервера.

Друзья видят Connection timed out или Connection refused

Проверь, что сервер запущен, версия клиента совпадает, адрес и порт введены правильно, а брандмауэр разрешает подключение. Для доступа извне также проверь настройки роутера и ограничения провайдера.

Сервер запускается, но сильно лагает

Проверь нагрузку на процессор и память, количество игроков, сущностей, модов и плагинов. Попробуй постепенно уменьшить view-distance и simulation-distance, а также изучи сообщения консоли. Высокий ping у игрока и низкий TPS сервера — разные проблемы.

После установки мода сервер не запускается

Останови сервер, убери последний добавленный файл и проверь журнал ошибки. Сверь версию Minecraft, загрузчик, Java, зависимости и совместимость каждого мода. Восстанови резервную копию, если это необходимо.

SECTION 01

What you need for your own server

A Minecraft Java Edition server is a separate program that runs the world and processes player actions. Your computer or rented host must stay online while friends are playing on a home-hosted server.

Before you begin, prepare:

  • A computer or hosting plan. More players, mods, plugins and builds generally require more CPU, memory and system stability.
  • A compatible Java version. It must match the Minecraft version and server software you choose.
  • A server folder. Keep server files separate from your Minecraft client folders.
  • Administrator access. Installing Java or changing firewall rules may require administrator permission.
  • Backups. Make a safe copy of your world before installing mods, plugins or updates.
Home server or hosting?

A home server can work well for a small group when the computer can stay on. Hosting is more convenient when the server must run around the clock or your home connection does not allow outside connections.

SECTION 02

Choose your server software

First decide what kind of server you want. Client mods and server plugins are not the same thing, and different mod loaders are not interchangeable.

VanillaThe official server without third-party modifications. A good choice for classic survival and a simple start.
PaperA Bukkit/Spigot-based server with plugin support and additional configuration. Commonly used for plugin-based servers.
FabricA mod loader for server mods and modpacks where flexibility is important. Check whether each mod is required on the server, client, or both.
Forge / NeoForgeMod loaders for modded servers. Use the appropriate installer and match the game, loader and required mod versions.
Do not mix incompatible files

Paper plugins are not installed as regular Forge mods. Do not drop a random JAR into the mods or plugins folder: check the platform documentation and the file's compatibility first.

SECTION 03

Install the right Java version

The server .jar file runs through Java. You do not always need the newest Java release; you need the version required by your exact Minecraft version and server project.

  1. Open the documentation or download page for your server software.
  2. Find the Java requirement for your Minecraft version.
  3. Install a compatible 64-bit Java build from a trusted source.
  4. Open a terminal or Command Prompt and run java -version to verify the installation.
Java requirements depend on the game version

For example, the current Paper version table lists Java 21 for Paper 1.20–1.21.11 and Java 25 for 26.1+. For other versions, follow their own requirements rather than copying a version number from this example.

If the java command is not found, Java may be missing or not added to PATH. Open a new terminal window after installing it and try again.

2

For Paper, use the official PaperMC downloads and select a build that matches your Minecraft version.

3

For Fabric, Forge or NeoForge, use the loader's official website and follow its server installation instructions.

4

SECTION 05

First launch and the EULA

The first launch creates configuration files and the world folder. The server may exit immediately at this stage; for Vanilla, this is expected when you still need to read and accept the license agreement.

  1. Open the server folder.
  2. Run the JAR through a terminal or a temporary start script. A Vanilla command usually looks like java -jar server.jar nogui (replace the filename with yours).
  3. After the first launch, find eula.txt.
  4. Open the Minecraft EULA link in the file or on the official website and read the terms.
  5. Only if you agree, change eula=false to eula=true and save the file.
  6. Start the server again.
Do not set eula=true automatically

Changing this value means you agree to the license. Do so only after reading the terms and deciding that you agree.

When the server starts successfully, the console will show a ready message, usually containing Done. Keep this window open while the server is running.

SECTION 06

Create a convenient start script

To avoid typing the command every time, create a start file in your server folder. On Windows, this can be start.bat; on Linux, start.sh. Use the exact name of your JAR file.

Windows example (Vanilla)

@echo off
java -Xms2G -Xmx4G -jar server.jar nogui
pause

Paper example

@echo off
java -Xms2G -Xmx4G -jar paper.jar --nogui
pause

Save the file with a .bat extension, not .txt. Double-clicking it will start the server. The pause command keeps the window open so you can read any error message.

What do the memory options mean?

  • -Xms2G — the initial Java memory allocation.
  • -Xmx4G — the maximum memory Java can use.
  • nogui or --nogui — starts without the graphical window, when supported by the selected server.
Do not allocate all available RAM

2G and 4G are example values, not universal recommendations. Leave memory for Windows, the Minecraft client and other programs. Requirements depend on players, mods, plugins and world size. Start with a moderate value and monitor memory usage.

SECTION 07

Configure server.properties

After the first launch, a server.properties file will appear in the server folder. Stop the server with the stop command before editing it, then open the file in a text editor. Save your changes and start the server again.

Useful core settings

gamemode=survivalDefault game mode: survival, creative, adventure or spectator.
difficulty=normalDifficulty: peaceful, easy, normal or hard.
max-players=10Maximum number of concurrent players. Choose a value your server can handle.
motd=My Minecraft ServerThe message shown in the server list.
server-port=25565The default Java Edition server network port. Change it only when needed and configure your network accordingly.
server-ip=Usually leave this blank. Do not enter a public IP or a random address; an incorrect value can prevent the server from starting.
online-mode=trueKeep enabled for normal account authentication. Do not disable it to bypass verification: this weakens security and allows name spoofing.
white-list=trueEnables the player allowlist. Add only people who should have access.
view-distance=8An example server view distance. Lowering it may reduce load but also changes how far players can see.
simulation-distance=6An example simulation distance. It affects the area in which the server updates the world.

Not every option is available or behaves the same way on all server builds. If a setting is missing, check the documentation for your platform. Change one or two values at a time and test the result.

SECTION 08

Whitelist, operators, mods and plugins

Allow only people you trust

Use these commands in the server console:

whitelist on
whitelist add PlayerName
whitelist list

To remove a player, run whitelist remove PlayerName. Enter the player's exact in-game name.

Assign operator permissions carefully

op PlayerName
deop PlayerName

An operator (OP) has broad administrative permissions. Do not give OP to everyone; a whitelist is usually enough for ordinary players.

Mods and plugins

  • Vanilla: does not support Bukkit plugins or Forge/Fabric mods without different server software.
  • Paper: uses the plugins folder. Download plugins from the project's official page and check version compatibility.
  • Fabric / Forge / NeoForge: server mods are placed according to the loader's instructions, often in a mods folder. Some mods must also be installed on the client.
Compatibility matters more than quantity

All players need matching Minecraft versions and the required loader/mod versions. Stop the server and make a backup before installing a new plugin or mod.

SECTION 09

Invite your friends

Test the server on your own computer first

When the server runs on the same computer, open Minecraft Java Edition using the same version and connect to localhost. If this works, the server is running locally.

Connecting on the same home network

  1. On the host computer, open Command Prompt and run ipconfig.
  2. Find the IPv4 address of the active network adapter, for example 192.168.1.25.
  3. Another player on the same network enters this local address in the server address field.

Letting friends connect over the internet

Direct outside connections usually require a firewall rule and TCP port forwarding for the server (25565 by default) to the host computer's local address. Exact router menus vary by model and ISP.

  1. Make sure the server starts reliably and works locally.
  2. Allow the server application through the firewall. Do not disable the firewall entirely.
  3. Ask the home network owner or the adult responsible for the router to help with router configuration.
  4. Share the connection address only with people you know and trust.
Do not post your home IP publicly

Your public IP can reveal information about your internet connection. Do not post it in public chats or websites. Do not configure port forwarding without understanding the implications. If your ISP uses CGNAT, ordinary port forwarding may not work; ask your provider about options or consider hosting/a private connection solution.

SECTION 10

Backups and updates

Your world is the most valuable part of the server. An update error, incompatible plugin or damaged file can cause progress to be lost. Make a backup before major changes.

1

Run save-all in the server console to save the world.

2

Shut down with stop. Wait until the server has fully closed.

3

Copy the entire server folder to another location or a separate drive. Do not keep the only backup beside the original.

4

Update the server, Java, mods and plugins one component at a time. Test the launch and check the console after each change.

Before updating Minecraft, check plugin, mod and loader compatibility. Do not open your only copy of a world in a new version before backing it up; reverting an upgraded world may be impossible or unsafe.

Use the stop command before closing

Do not close the server window or shut down the computer while the world is saving. The stop command lets the server shut down cleanly.

SECTION 11

Fix common problems

The server says I need to accept the EULA

Open eula.txt, read the agreement and, only if you agree, change eula=false to eula=true. Save the file and start the server again.

UnsupportedClassVersionError appears

The Java version is often incompatible. Check the Java requirement for your exact server version, install it and verify with java -version.

Failed to bind to port appears

The port may already be in use, or server-ip may be incorrect. For a normal home setup, leave server-ip= blank and check whether another server instance is running.

Friends get Connection timed out or Connection refused

Check that the server is running, the client version matches, the address and port are correct, and the firewall allows the connection. Outside access also depends on router settings and ISP restrictions.

The server starts but lags badly

Check CPU and memory usage, player count, entities, mods and plugins. Try lowering view-distance and simulation-distance gradually and review console messages. A player's high ping and low server TPS are different issues.

The server stops after I install a mod

Stop the server, remove the last added file and inspect the error log. Check Minecraft, loader and Java versions, dependencies and mod compatibility. Restore your backup if needed.

SUMMARY

Quick setup checklist

Check these items before inviting friends to your server.

✓ Chosen the right server type: Vanilla, Paper, Fabric, Forge or NeoForge
✓ Installed a compatible Java version
✓ Kept server files in a separate folder
✓ Read and consciously accepted the EULA
✓ Started the server successfully and tested localhost
✓ Configured server.properties and left server-ip blank unless there is a specific reason to change it
✓ Enabled the whitelist and gave OP only to trusted people
✓ Created a backup of the world and server files
✓ Handled network settings carefully without disabling the firewall
The most important advice

Start with a simple server, test it locally, configure access, and only then add plugins, mods and extra features. Create a backup before every major update.
